# 01-basics

Practice questions for Java fundamentals. Each program is in its own file, and the file name matches the class name.

| # | Class | Question |
|---|-------|----------|
| 1 | `PrintName` | Print your name, city, and goal on 3 separate lines. |
| 2 | `Variables` | Declare one variable each of type `int`, `double`, `char`, `boolean`, and `String`. Print all five with labels. |
| 3 | `AddTwoNumbers` | Store two numbers in variables and print their sum. |
| 4 | `ReadInput` | Use `Scanner` to read a name and age, then print: `Hi Rahul, you are 21 years old.` |
| 5 | `Calculator` | Read two numbers and print the sum, difference, product, quotient, and remainder. |
| 6 | `AreaOfCircle` | Read the radius (a `double`) and print the area using `Math.PI`. |
| 7 | `SwapNumbers` | Swap two variables using a third variable. Print both before and after. |
| 8 | `CelsiusToFahrenheit` | Read a Celsius value and print the Fahrenheit value (`F = C * 9/5 + 32`). |
| 9 | `SimpleInterest` | Read principal, rate, and time, then print the interest (`P * R * T / 100`). |
| 10 | `CheckTypes` | Store `9.99` in a `double`, cast it to `int`, and print both. Then divide `7 / 2` using ints and again using doubles, and print both results. |
