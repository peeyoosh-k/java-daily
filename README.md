## 📌 Rules I follow

- Write the code by hand, then run it and test it with known values.
- Learn every concept in a topic, not just finish a fixed number of questions.
- Commit with clear messages, like `basics: add Calculator and AreaOfCircle`.
- Revisit and improve old programs as new concepts are learned.
